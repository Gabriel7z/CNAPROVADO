# CNAPROVADO

Site no GitHub Pages: **https://gabriel7z.github.io/CNAPROVADO/**

Tópico 1 — Fontes, Conceito e Objeto do Direito Administrativo (Thállius Moraes). 50 questões.

O HTML/CSS/JS está na branch `gh-pages`. O workflow `.github/workflows/deploy-pages.yml` publica o site.

Para o GitHub Pages ir ao ar (uma vez só, no GitHub — não no computador):

1. [Deixar o repositório público](https://github.com/Gabriel7z/CNAPROVADO/settings) (plano Free não publica Pages de repo privado)
2. Em [Settings → Pages](https://github.com/Gabriel7z/CNAPROVADO/settings/pages) escolha **GitHub Actions** ou a branch **gh-pages** / root
